# Проверка плееров YummyAnime — 25 ноября 2026

## Выбор в интерфейсе

Релиз → плеер → озвучка → серия. Для плеера показано число озвучек, для озвучки — число серий. Возврат сохраняет выбранный плеер, озвучку и серию.

## Автоматические проверки

Проверены отдельные списки озвучек разных плееров, навигация стрелками/OK/Back, восстановление фокуса, удаление iframe при выходе и обработка сетевой ошибки. На имитированных iframe проверены точные протоколы play/pause/seek для Kodik, CVH, Aksor и VK, а также отсутствие ложных кнопок API для Alloha. Имитированный плеер не подтверждает работу настоящего видеопотока.

## Реальные проверки

Из API первых 10 релизов каталога собраны пять различных плееров. Для каждого проверен один пример в iframe нашего интерфейса в Chrome на компьютере. Проверка ограничена этой выборкой и не охватывает все релизы и озвучки. Ожидание запуска — около 26 секунд после загрузки интерфейса.

| Плеер | Результат |
| --- | --- |
| Kodik | Видео запущено через команду нашего интерфейса; получены сообщения воспроизведения, currentTime превысил 11 секунд, readyState=4, ошибки video нет. |
| Aksor | Видео загружено; currentTime превысил 6 секунд, readyState=4, ошибки video нет. В конце проверки стояло на паузе после команд управления. |
| Alloha | Проверенный пример вернул HTTP 404 и собственное сообщение об ограничении контента в регионе. Обход ограничения не выполнялся. |
| CVH | Страница iframe загрузилась (HTTP 200), но воспроизведение за время проверки не подтвердилось. Доступный протокол управления подключён, требуется дополнительная проверка запуска. |
| VK | Страница iframe загрузилась (HTTP 200), но воспроизведение за время проверки не подтвердилось. Доступный протокол управления подключён, требуется дополнительная проверка запуска. |

Физический Philips SAPHI в этой проверке не участвовал. Совместимость декодирования, звука и длительного воспроизведения на телевизоре пока не подтверждена. Реклама и ограничения источников сохраняются.
