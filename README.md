# AniLiberty для Philips SAPHI

Неофициальный веб-клиент AniLiberty для телевизоров Philips с системой **SAPHI**. Просмотр аниме и управление обычным пультом — через **MediaStationX** или браузер телевизора.

Приложение размещено на **GitHub Pages**: постоянно включённый компьютер, локальный сервер и установка Tizen-виджета не нужны.

[Открыть приложение](https://mvoskorpion-hash.github.io/aniliberty-philips-saphi/?tv=philips) · [Сообщить о проблеме](https://github.com/mvoskorpion-hash/aniliberty-philips-saphi/issues)

## Возможности

- Главная страница, каталог, расписание и коллекции.
- Просмотр серий с выбором доступного качества.
- Навигация по интерфейсу с пульта.
- Адаптация JavaScript и интерфейса для старых браузеров SAPHI.
- Запуск из MediaStationX через отдельную плитку AniLiberty.

## Запуск через MediaStationX

1. Откройте **MediaStationX** на телевизоре.
2. Перейдите в **Settings → Start Parameter → Setup**.
3. Введите короткий параметр:

   ```text
   id:trl:2236r8ja
   ```

4. Включите **HTTPS** — значок замка должен быть активен.
5. Подтвердите настройку и откройте плитку **AniLiberty**.

Короткий параметр ведёт к файлу запуска этого репозитория. При обновлении приложения менять его не нужно.

Если короткая ссылка недоступна, используйте [прямую ссылку на файл запуска MSX](https://mvoskorpion-hash.github.io/aniliberty-philips-saphi/msx/start.json).

## Запуск через браузер

Откройте в браузере телевизора:

```text
https://mvoskorpion-hash.github.io/aniliberty-philips-saphi/?tv=philips
```

Параметр `?tv=philips` включает режим Philips, в том числе когда браузер не сообщает модель телевизора.

## Управление

| Кнопка пульта | Действие |
| --- | --- |
| Стрелки | Перемещение по меню и элементам плеера |
| OK / Enter | Открытие выбранного элемента или подтверждение |
| Back / Назад | Закрытие меню, возврат с текущего экрана |
| Play / Pause | Воспроизведение и пауза |
| Перемотка вперёд / назад | Перемещение на 10 секунд, если браузер передаёт эти кнопки |
| Stop | Закрытие плеера, если браузер передаёт эту кнопку |

Для выхода из приложения можно использовать кнопку **Home** телевизора. Доступность отдельных кнопок зависит от браузера и MediaStationX.

## Совместимость

Адаптация ориентирована на **Philips 50PUS7506/60 с SAPHI**. Пользователь подтвердил запуск интерфейса и воспроизведение на этой модели. Для других телевизоров Philips совместимость пока не подтверждена.

Каталог и навигация проверялись в Chrome с имитацией отсутствующих браузерных API. Расположение элементов плеера проверялось при разрешениях 960×540, 1280×720 и 1920×1080. Эти проверки не заменяют проверку на физическом телевизоре.

Для работы нужны интернет и доступ телевизора к HTTPS API и видеопотокам AniLiberty. Доступное качество и воспроизведение зависят от конкретного видео и возможностей телевизора.

## Обновления и решение проблем

Обновления появляются по прежнему адресу автоматически. Если остался старый интерфейс, полностью закройте MediaStationX и запустите его снова; при необходимости очистите кеш приложения или браузера.

Если каталог пустой или видео не запускается:

- Проверьте интернет на телевизоре и активный HTTPS в настройке MSX.
- Попробуйте открыть приложение через браузер и выбрать другое качество видео.
- [Создайте issue](https://github.com/mvoskorpion-hash/aniliberty-philips-saphi/issues), указав модель телевизора, способ запуска, название и номер серии, выбранное качество и текст ошибки. Фото экрана поможет воспроизвести проблему.

В версии **1.0.8** расширена замена неподдерживаемых значков на SVG, исправлены обработчик обновления позиции видео и повторное подключение кнопки полного экрана. Сведения о проверках и ограничениях — в [QA.md](QA.md).

## Устройство репозитория

| Файл или каталог | Назначение |
| --- | --- |
| `source/` | Исходники оригинального клиента |
| `build.cjs` | Адаптация и сборка для SAPHI |
| `philips-boot.js` | Совместимость браузера, обработка воспроизведения и диагностика |
| `web/` | Готовые файлы приложения для GitHub Pages |
| `publish.cjs` | Генерация файлов запуска MediaStationX |
| `.github/workflows/pages.yml` | Автоматическая публикация из ветки `main` |

Workflow публикует готовый каталог `web/` и генерирует MSX-конфигурацию с адресом GitHub Pages. Он **не запускает сборку `build.cjs`**: при изменении исходников необходимо также обновить готовые файлы.
